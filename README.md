 Blinking LED – Arduino Project

This simple Arduino project uses digital output to blink an LED on and off at 1-second intervals.


- pinMode()
- digitalWrite()
- delay()
- Digital output basics

 Circuit Diagram
- Arduino pin 13 → 220Ω Resistor → LED → GND
- Or use built-in LED on pin 13
Tinkercad
Simulation created using [Tinkercad Circuits](https://www.tinkercad.com/)

How to Run
1. Copy the `.ino` code into Arduino IDE or Tinkercad
2. Upload to Arduino or run simulation
